# Smart Employee Management Dashboard

A modern and responsive **Employee Management Dashboard** developed using **HTML5** and **CSS3**. This frontend-only project provides a clean, user-friendly interface for managing employee information through multiple dashboard pages.

## 🚀 Features

- Modern and Responsive UI
- Professional Dashboard Layout
- Employee List Page
- Employee Details Page
- Add Employee Form
- Reports Dashboard
- User Profile Page
- Settings Page
- Sidebar Navigation
- Responsive Design for Desktop and Mobile
- Clean and Organized Code

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open **index.html** in any web browser.
